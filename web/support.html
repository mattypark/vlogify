common questions

My friend can’t join. The room is full, or the code has a typo. Codes never contain I, L, O or U. The owner can share a fresh code from the room’s menu.

I didn’t get a ping. Check Settings → Notifications → vlogify is allowed and no Focus is silencing it. Pings only come from logs with friends; solo vlogs never ping.

I missed an hour. That tile stays empty. You cannot post into a past hour, and there are no retakes — that is the whole idea.

Saving failed. Allow “Add to Photos” for vlogify in Settings → Privacy → Photos, and make sure there is space on the phone.

Change the language. Profile → language. The app asks on first launch.

Delete my account. Profile → delete account. Everything goes, immediately.
